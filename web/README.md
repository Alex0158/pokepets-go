# Pokepet Go web skeleton

Run `npm install` and `npm run dev` in this directory. Open http://localhost:3000; the backend health endpoint is `/api/health`.

Run `npm run build` and `npm run typecheck` to verify the application. The existing single-user prototype remains in the repository root. This skeleton does not yet connect the database, multiplayer, 2.5D map, or AI.

See [skeleton.md](docs/skeleton.md) and the team Space architecture and roadmap for planned boundaries.
