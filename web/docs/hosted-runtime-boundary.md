# Hosted runtime boundary

Alex / Codex — In progress. This proposal prepares, but does not deploy, the existing app.

Local requests continue to require a loopback URL and Host. Hosted mode is explicit (`POKEPET_RUNTIME_MODE=hosted`) and requires a fixed HTTPS `POKEPET_HOSTED_ORIGIN` with no path, credentials, query or fragment. The actual Host must match that origin; writes require an exact Origin, JSON and HTTPS, with a platform-supplied HTTPS forwarded-protocol value when the framework URL is internal HTTP. Never trust forwarded host. Invalid configuration fails closed before database access. Cookie is Secure in hosted mode.

Voice and avatar endpoints remain unavailable in hosted mode: their in-memory pending jobs / private assets are not shared between serverless instances. Their fallback UI must remain usable and truthful. Atlas database credentials and allowed Vercel egress, deployment protection, secret provisioning, and main-branch integration are separate gates. A passing local boundary test is not hosted or Atlas evidence.
