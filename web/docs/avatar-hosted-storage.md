# Hosted avatar storage prototype

Alex / Codex — In progress, 1 November 2026. Opt-in implementation and local evidence only. The shared hosted boundary stays with its owner; deployment, permissions, credentials and hosted acceptance are separate gates.

## Smallest contract

Keep the existing authenticated `/api/avatars` API and callback. With `POKEPET_AVATAR_STORAGE=mongo`, POST waits for generation/validation and stores its terminal result before returning. There is no required background worker after the response. Other instances read the same private job/asset record; no sticky routing is required. Local memory mode remains available. Hosted mode must explicitly select Mongo storage and OpenAI provider; it stays disabled by default.

Original owner/pet images exist only in the request's memory, never MongoDB, disk or logs. The request stores only owner ID, request ID, input digest/policy/subject, bounded status and the generated output. Generated PNGs and jobs expire from access after five minutes. MongoDB TTL removes expired records later; physical removal/backups are not an immediate-deletion guarantee. A small durable budget record retains at most two hashed owner/request claims, without photo bytes or the photo digest, to prevent replay charging after a job's TTL cleanup. It is not automatically reset by process restart or asset expiry.

Before provider work: require the existing uploader consent, validate PNG/JPEG decode and <=3 MiB raw input, claim a unique owner/request receipt, then atomically reserve one of at most two DB-wide provider attempts. Exact retries return the same receipt; conflicting payloads fail. A crashed or timed-out request is never automatically taken over or regenerated. Polling marks an abandoned running job failed after its deadline. Cancellation revokes delivery across instances; an upstream request in another instance can continue until request completion/timeout and may still be billed. Late results cannot overwrite canceled/expired jobs. No points, missions, matches or player profiles are modified.

JSON request cap: 4,300,000 bytes; a 3 MiB file encodes to 4,194,304 base64 bytes plus small JSON metadata, below Vercel's 4.5 MB limit. Generated image cap: 4 MiB. Server generation deadline: 120 seconds; route `maxDuration`: 180 seconds; browser submit timeout: 150 seconds. Actual deployed plan/proxy/timeout behavior still needs verification.

Shared hosted guard changes belong to its owner and must follow the remaining verification; no guard bypass is implemented here.

Hosted quota integration: compose the existing non-resetting avatar cap with the shared `configuredHostedAICap` / `reserveHostedAICall` adapter. Require a valid `POKEPET_HOSTED_OPENAI_CALLS_PER_DAY` before hosted OpenAI setup; reserve an atomic shared slot immediately before the provider HTTP attempt. Missing/exhausted/unavailable quota fails closed; local mode has no shared-quota hook. Provider-error attempts retain their reservation; neither quota is a currency budget or an exactly-once billing guarantee. Preserve the shared hosted guard until this integration and hosted activation are accepted.
