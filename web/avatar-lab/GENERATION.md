# Sample asset provenance

`assets/sample-puppy-sheet.png` is an original synthetic sample created with the built-in `image_gen` tool on 1 November 2026. No real owner or pet images were supplied. The tool does not expose the exact generating model; do not label this output as a verified GPT Image 2.5 API result. The image was copied unchanged into this module. Its actual PNG dimensions are 1254 × 1254 with RGBA, so the manifest uses explicit integer cell boundaries rather than assuming 1024 × 1024.

This is a single generated 4 × 4 game atlas with sample-level pose alignment. It is not a validated Hatch Pet/Codex package. Production work should generate and review state strips independently, check identity, feet/baseline and transparent margins, then assemble exact cells. No third-party pet artwork or code was copied. Owner and fallback SVGs are original code-drawn presets; the map uses original primitive geometry. Three.js is read from the existing installed dependency.

Row 4: four sequential surprised/hurt reaction poses: startled, small flinch, recover, neutral. Keep exact consistent character identity, color, scale and camera angle in all 16 frames.
